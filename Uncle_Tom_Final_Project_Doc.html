1. Executive Summary & Concept

Uncle Tom is an enterprise-grade digital marketplace designed to unlock astronomical tourism, luxury stargazing retreats, and telescope access worldwide. The platform enables curious travelers, astrophotographers, and scientific observatories to connect through a verified reservation engine backed by live sky-condition telemetry.

Unlike standard tourism platforms, astronomy tourism is heavily dependent on atmospheric visibility, lunar phases, and specialized optical instrumentation. Uncle Tom bridges this technological gap with:

  • Bortle Class 1-3 Dark Sky Destinations: Curated locations with pristine night skies (Hanle in Ladakh, Atacama Desert, Canary Islands, Mauna Kea, Thar Desert, and the Australian Outback).
  • Real-Time Atmospheric Seeing Telemetry: Cloud coverage, seeing indices (arcseconds), and moon illumination calculation.
  • Clear-Sky Guarantee: Automated, zero-friction rescheduling if cloud cover exceeds 40%.

Key Infrastructure Components

Layer Technology Role & Purpose
Edge & CDN AWS CloudFront + Route 53 + WAF Edge caching for high-res galaxy images, DDoS mitigation, sub-50ms latency.
Compute / Pods Amazon EKS (Kubernetes 1.30+) Autoscaling microservices deployed across 3 Availability Zones.
Event Streaming Apache Kafka (Amazon MSK) Decoupled asynchronous event pipeline for instant ticketing & alerts.
Relational DB Amazon Aurora PostgreSQL ACID compliance for user accounts, reservations, and payment logs.
In-Memory Cache Redis Cluster (Amazon ElastiCache) Sub-millisecond slot lock and weather forecasting cache.

4. External API Integrations

  • NASA Open APIs (APOD & NeoWs): Indexes real-time astronomical imagery and orbital tracks for Near-Earth Objects.
  • Open-Meteo & Seeing Models: Computes high-altitude seeing index (arcseconds), cloud density, and transparency.
  • Escrow Processing (Razorpay Route / Stripe Connect): Facilitates instant split-settlements and automated partner commission handling.
  • OpenAI Astronomy Engine: Drives the conversational Ask Stargazer AI assistant widget with domain-expert sky advice.

5. Core Functional Modules & User Journeys

Customer Flow (5-Step Checkout)

  1. Review Experience: Personalize with amenities (e.g., Heated Blanket, Hot Cocoa, Astro Portrait).
  2. Schedule & Slots: Dynamic slot picker with real-time seat availability and sky quality badge.
  3. Guest Details: Input lead guest and special requests (with 1-click test autofill).
  4. Secure Payment: Credit/Debit card, UPI, or Net Banking with live 3D card preview.
  5. Instant Confirmation: Generates booking ID, QR code, downloadable voucher, and .ics calendar file.
